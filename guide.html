컴포넌트 가이드

지도 퍼블 공통 UI. 미리보기에서 상태를 확인하고, 복사로 마크업을 가져간다. 클래스는 화면에서 쓰는 그대로다. 지도 미리보기는 map.html.

시작

각 섹션에 미리보기와 복사 가능한 예제가 있다. 폼 컨트롤은 네이티브 input을 숨기고 박스만 그린다. 클래스는 화면에서 쓰는 그대로다.

모달

.dlg #metaModal

마크업은 partials/modal.hbs. 기본 딤은 data-dimmed="true". 열기: MapUI.openModal('metaModal', { dimmed: true }). 닫기: 닫기 버튼, 딤 클릭, Esc. 닫으면 연 버튼으로 포커스 복귀. 모달 안 Tab 순환.

지도에서 보기

상위 탭 메타정보 / 데이터 보기. 메타 안 아코디언 4종. MapUI.openModal('metaModal', { tab: 'spatial' }). 닫기: 닫기 버튼, 딤, Esc. 미리보기 #modal #modal-spatial #modal-marine #modal-model #modal-data.

JavaScript 
MapUI.openModal('metaModal', { dimmed: true, tab: 'overview' })
MapUI.setModalTab('spatial')
MapUI.closeModal('metaModal')

document.addEventListener('map:modal-tab', (e) => {
  const { tab } = e.detail
})
